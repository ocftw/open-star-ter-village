# Event Cards

> **Source:** [Event-card PDF (Google Drive)](https://drive.google.com/file/d/1kiycKTIw1vrM375p9jAYX2ZyVBSuZyx0/view?usp=sharing)  
> **PDF title:** `（英）開源事件卡`  
> **Pages:** 15 (1 divider/card-back page and 14 card faces)

Cards printed with a `B` marker are used in both Standard and Simplified modes.
Unmarked cards are used only in Standard Mode. See the
[rulebook](./rulebook.md) for deck setup.

| PDF page | Event | `B` marker | Printed effect |
| ---: | --- | :---: | --- |
| 2 | You're released from your duties | Yes | Discard all labor cards in the labor card section and replenish right away. |
| 3 | Side hustle | Yes | The first labor card played by everyplayer when initiating a project or recruiting talents can be placed in any project, regardless of the labor requirement listed. |
| 4 | Old and Poor | No | No one can grow the Open Source Tree this round. |
| 5 | Github is down | No | No one can play Initiator Contribution this round. |
| 6 | Budweisavirus | No | Move all the contribution tokens 1 square backward. Nothing happens if it's already at 1. |
| 7 | A Shark Bites the Submarine Cable | No | If there are two or more projects on the project board, no one can initiate a project this round. |
| 8 | The end of the world! | No | When this card is flipped, the game ends after this round. Each unused action point equals 1 influence point. |
| 9 | The Four Freedoms | Yes | Replenish two labor cards to labor card section right away. The last player will choose two labor cards to discard at the end of this round. |
| 10 | The Digital Minster | Yes | Move all contribution tokens on open government projects 1 sqaure forward, but cannot exceed the demands of the projects. |
| 11 | Annual Financial Report | Yes | All projects that end in this round are granted 2 extra influence points to the initiators. |
| 12 | Apologies to my liver | No | Every player can recruit talents once again without spending any action points this round after their first time. |
| 13 | Subsisdies for the Youth | Yes | The player with the lowest influence points now can use the gray communal action token. If there are more than one player with the lowest influence points, no one can use it. |
| 14 | The Carbonara method | Yes | When initiator contribution takes place this turn, gain 1 more contribution point. |
| 15 | Unpaid vacation | No | No one can play Doin' Overtime this round. |
