# 文件用截圖

`homepage/README.md` 內以 HTML 註解標記了三個待補的截圖位置。補上檔案後，把該行註解改成 Markdown 圖片語法即可。

| 檔名 | 內容 | 取得方式 |
| --- | --- | --- |
| `cms-login.png` | Decap CMS 登入畫面，含「使用你的 GitHub 帳號來進行登入」按鈕 | 以未登入狀態開啟 `/admin/` |
| `github-authorize.png` | GitHub OAuth 授權畫面 | 點擊登入按鈕後出現，需登入 GitHub |
| `github-write-access.png` | 儲存庫 Settings → Collaborators and teams 邀請畫面 | 需組織管理者權限 |

截圖請避免包含個人 email、token、或其他帳號的可識別資訊。
